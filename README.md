## Course Overview

Operating Systems at FAST-NUCES Islamabad, Spring 2025, with the labs done on Linux in C and C++. The course folder has the lecture slides grouped by topic, chapter summaries, my study notes, two textbooks, assignments, quizzes and the final project statement. The lab folder has the lab manuals, the example programs from each lab and my solutions to the lab tasks.

## Topics Covered

| Unit | Topics |
|---|---|
| **Unit 1 – Basics & processes** | OS structure, system calls, Docker, processes, PCB, fork and exec. |
| **Unit 2 – IPC & scheduling** | Pipes, named pipes, signals and CPU scheduling algorithms. |
| **Unit 3 – Threads & synchronization** | POSIX threads, critical sections, Peterson, Bakery, mutexes and semaphores. |
| **Unit 4 – Deadlocks & memory** | Deadlock handling, address binding, paging and memory policies. |

## Building the Code

The labs use Linux system calls (fork, exec, pipes, signals, pthreads, semaphores), so build them on Linux, WSL or inside a Docker container:

```bash
git clone https://github.com/rohaan2802/OS_Repository.git
cd "OS_Repository/OS LAB/LAB #05/i222327_lab_5"
gcc task2.c -o task2
./task2
```

Add `-lpthread` for programs that use threads and `-lrt` for POSIX semaphores and shared memory, for example `g++ task3.cpp -o task3 -lpthread -lrt`. Compiled executables are not stored in the repository; `.gitignore` keeps them out.
