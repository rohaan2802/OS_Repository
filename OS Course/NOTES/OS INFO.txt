The number of execution units in a CPU depends on the number of cores and their individual architectures.

1 Understanding Execution Units in a CPU
Each core in a CPU has its own execution units, which are responsible for performing computations. These typically include:

Arithmetic Logic Units (ALUs) – Perform arithmetic (addition, subtraction, etc.) and logical operations.
Floating-Point Units (FPUs) – Handle complex mathematical calculations.
Load/Store Units – Manage memory access.
Branch Units – Handle decision-making operations.
A modern CPU core usually has multiple execution units for parallel processing.

2 How Many Units in the Whole CPU?
If each core has its own set of execution units, then:

Total Execution Units = (Number of Cores) × (Execution Units per Core)

For example:

A 4-core CPU, with 6 execution units per core, has 4 × 6 = 24 execution units.
A 16-core CPU, with 8 execution units per core, has 16 × 8 = 128 execution units.
Modern CPUs often share some resources (like caches), but execution units inside cores remain separate.

3 Does Hyper-Threading or SMT Affect This?
Hyper-Threading (Intel) or Simultaneous Multithreading (SMT, AMD) allows one core to handle multiple threads.
However, this does not increase the number of execution units—it only improves utilization of existing ones.

Conclusion:
The total number of execution units in a CPU depends on:

Number of cores
Number of execution units per core
So, if your CPU has 8 cores with 6 execution units per core, the total would be 8 × 6 = 48 execution units in the whole CPU.
