chrono in C++ (Simple Explanation)
chrono is a C++ library used for handling time-related operations, such as measuring time intervals, setting delays, or getting the current time. It is part of the <chrono> header and provides precise ways to work with time.

Key Concepts:
Time Points – A specific point in time (e.g., current system time).
Durations – The difference between two time points (e.g., 5 seconds).
Clocks – A way to get the current time (e.g., system clock, steady clock).
Basic Example:

include <iostream>
include <chrono>
include <thread>

int main() {
    // Get start time
    auto start = std::chrono::high_resolution_clock::now();

    // Simulate some work (sleep for 2 seconds)
    std::this_thread::sleep_for(std::chrono::seconds(2));

    // Get end time
    auto end = std::chrono::high_resolution_clock::now();

    // Calculate duration
    auto duration = std::chrono::duration_cast<std::chrono::milliseconds>(end - start);

    std::cout << "Elapsed time: " << duration.count() << " milliseconds\n";

    return 0;
}
Explanation:
std::chrono::high_resolution_clock::now() -> Gets the current time.
std::this_thread::sleep_for(std::chrono::seconds(2)) -> Pauses execution for 2 seconds.
end - start -> Finds the duration between two time points.
std::chrono::duration_cast<std::chrono::milliseconds>(...) -> Converts the duration to milliseconds.
count() -> Extracts the numerical value of the duration.
Use Cases:
Measuring execution time of a program
Creating time delays (sleep_for)
Handling timestamps (e.g., logging events)

exit and _Exit in c/cpp

In C and C++, exit() and _Exit() are both functions used to terminate a program, but they have key differences in their behavior.

1. exit(int status) (Defined in <stdlib.h> for C and <cstdlib> for C++)
Performs clean-up operations before terminating the program.
Calls functions registered with atexit().
Flushes and closes all open I/O streams (like stdout and stderr).
Deallocates some dynamically allocated memory managed by the runtime.
Returns the status code to the operating system (typically 0 for success and non-zero for failure).
Example:

include <iostream>
include <cstdlib>

void cleanup() {
    std::cout << "Performing cleanup before exit." << std::endl;
}

int main() {
    std::atexit(cleanup);  // Register cleanup function
    std::cout << "Exiting program..." << std::endl;
    exit(0);
}
Output:

Exiting program...
Performing cleanup before exit.
2. _Exit(int status) (Defined in <stdlib.h> for C and <cstdlib> for C++)
Immediately terminates the program without cleanup.
Does not call functions registered with atexit().
Does not flush or close I/O streams.
Does not deallocate dynamic memory managed by the runtime.
Returns the status code to the operating system.
Example:

include <iostream>
include <cstdlib>

int main() {
    std::cout << "This message may not appear!" << std::endl;
    _Exit(0);
}
Output (may vary):

(No output, or incomplete output due to buffering)
Key Differences
Feature		          exit(int status)	         _Exit(int status)
Calls atexit() functions	 Yes 		 No
Flushes output buffers	 Yes		 No
Closes open file streams	 Yes		 No
Deallocates runtime memory	 Yes		 No
Terminates the program	 Yes		 Yes

When to Use Which?
Use exit() when you want proper cleanup before termination.
Use _Exit() when you need immediate termination, such as in cases of fatal errors or when cleanup functions might interfere with proper shutdown.

atexit() in C/C++
The atexit() function is used to register functions that should be executed automatically when the program terminates normally (via exit() or returning from main()). It allows you to specify cleanup tasks like releasing resources, closing files, or printing messages before the program exits.

include <cstdlib>  // or <stdlib.h> for C

int atexit(void (*func)(void));
func is a pointer to a function that takes no arguments and returns void.
Returns 0 on success and non-zero if registration fails (e.g., too many functions registered).

Example Usage

include <iostream>
include <cstdlib>

void cleanup() {
    std::cout << "Cleanup function executed before exit!" << std::endl;
}

int main() {
    std::atexit(cleanup);  // Register cleanup function
    std::cout << "Main function is ending." << std::endl;
    return 0;  // This triggers the cleanup function
}
Output:

Main function is ending.
Cleanup function executed before exit!
Multiple Calls to atexit()
You can register multiple functions with atexit(). They will be executed in reverse order of registration (LIFO – Last In, First Out).

include <iostream>
include <cstdlib>

void first() { std::cout << "First cleanup!\n"; }
void second() { std::cout << "Second cleanup!\n"; }

int main() {
    std::atexit(first);
    std::atexit(second);  // This gets executed first (LIFO)
    std::cout << "Main is exiting...\n";
    return 0;
}
Output:

Main is exiting...
Second cleanup!
First cleanup!

Key Points
Feature	Behavior
Function limit	Implementation-defined (typically at least 32)
Order of execution	Reverse order (LIFO)
Works with exit()?	 Yes
Works with _Exit()?	 No (ignored)
When to Use atexit()
To clean up resources (e.g., close files, free memory).
To log exit messages before program termination.
To ensure proper cleanup when exit() is used.

Q: Explain fflush in c in easy words also to clear the buffer to make it reuse for other i/o fflush is used?
----------------------------------------------------------------------
In C programming, fflush() is a function used to clear (flush) the output buffer of a stream. It is commonly used with stdout (standard output) to ensure that any pending output is written immediately to the console.

How fflush() Works?
When you use printf() or other output functions, the data might not be printed immediately because of buffering (data is stored temporarily before being displayed). fflush(stdout); forces the buffer to empty, making sure all the stored data is displayed right away.

Example:
include <stdio.h>

int main() {
    printf("Hello, ");
    fflush(stdout);  // Ensures "Hello, " is printed immediately
    printf("World!\n");
    return 0;
}
Without fflush(stdout);, the program might delay printing "Hello, " until it collects more data.

Can fflush() Clear Input Buffer?
Using fflush(stdin); (to clear the input buffer) is not recommended because its behavior is undefined in C. Instead, use methods like:

getchar() in a loop
scanf(" %c", &var); (with a space before %c)
while (getchar() != '\n'); (to consume leftover characters)
Conclusion
fflush(stdout); is useful to clear output buffers.
Avoid fflush(stdin); for input clearing—use safer alternatives.

For Input Buffers (stdin)

while (getchar() != '\n'); -> To clear extra characters from the input buffer.

Q: Why we use arguments with cin.ignore?
----------------------------------------
In C++, we use arguments with cin.ignore() to specify how many characters to discard and where to stop while clearing the input buffer.

Syntax of cin.ignore()
cin.ignore(n, delim);
n -> Number of characters to ignore (default: 1).
delim -> Stops ignoring when this delimiter is found (default: EOF).
Why Use Arguments?
To Clear Leftover Input (Buffer Cleanup)

When cin reads a value, extra characters (like \n from pressing Enter) remain in the buffer.
If we don’t clear them, they may interfere with future inputs.
Example:

include <iostream>
using namespace std;

int main() {
    int num;
    cout << "Enter a number: ";
    cin >> num;

    // Clear leftover input (e.g., Enter key '\n')
    cin.ignore(1000, '\n');

    cout << "Enter your name: ";
    string name;
    getline(cin, name);  // Works correctly now
    cout << "Hello, " << name << "!\n";

    return 0;
}
Why cin.ignore(1000, '\n');?

1000 -> Ensures we discard up to 1000 characters (enough to clear unwanted input).
\n -> Stops ignoring once a newline is found.
To Handle Invalid Input

When a user enters the wrong type (e.g., letters instead of a number), cin.fail() is set.
We must clear the error state (cin.clear()) and remove bad input (cin.ignore()) before retrying.
Example:

int age;
cout << "Enter your age: ";
cin >> age;

if (cin.fail()) {
    cin.clear();         // Clear error state
    cin.ignore(1000, '\n');  // Remove invalid input
    cout << "Invalid input. Please enter a number.\n";
}
What Happens If You Don't Use cin.ignore()?
Leftover \n can cause getline() to skip input.
Old or invalid input remains in the buffer, affecting the next cin operation.
Summary
cin.ignore(n, '\n'); clears leftover input to prevent issues.
Used after cin.clear(); to fix invalid input errors.
Helps prevent unexpected behavior with getline().

Q: When buffer memory automatically clears in which cases?
----------------------------------------------------------
When Does the Buffer Automatically Clear (Flush) in C?
The buffer automatically clears (flushes) in certain situations, depending on the buffering mode and specific triggers. Here are the key cases:

1. When a Newline (\n) is Encountered (Line Buffering)
Standard output (stdout) is usually line-buffered in terminals.
The buffer is flushed automatically when a newline (\n) is printed.
Example:

include <stdio.h>
int main() {
    printf("Hello, World!\n");  // '\n' causes an automatic flush
    return 0;
}
Output appears immediately because \n triggers a flush.

2. When the Buffer is Full (Full Buffering)
If output is written to a file or large stream, it is usually fully buffered.
The buffer is flushed automatically when it reaches its maximum size.
Example:

include <stdio.h>
int main() {
    FILE *file = fopen("output.txt", "w");
    for (int i = 0; i < 10000; i++) {
        fprintf(file, "Data %d ", i);  // Buffer fills up and flushes automatically
    }
    fclose(file);
    return 0;
}
Flush happens when the buffer is full.

3. When the Program Ends Normally (return 0; or exit())
Before exiting, C automatically flushes all open output buffers.
Example:

include <stdio.h>
int main() {
    printf("Program is ending...");
    return 0;  // Buffer flushes automatically before exit
}
No need for fflush(stdout); before return 0;.

4. When Switching from Output (printf) to Input (scanf)
When switching from output (stdout) to input (stdin), the buffer is automatically flushed.
Example:

include <stdio.h>
int main() {
    printf("Enter a number: ");  // Buffer flushes before taking input
    int num;
    scanf("%d", &num);
    return 0;
}
Flush happens before scanf() starts.

5. When Using fflush(stdout); (Manual Flushing)
If none of the above cases happen and you want immediate output, use fflush(stdout);.
Example:

include <stdio.h>
include <unistd.h>  // For sleep function
int main() {
    printf("Loading...");
    fflush(stdout);  // Flush immediately, ensuring "Loading..." appears before delay
    sleep(2);
    printf(" Done!\n");
    return 0;
}
Ensures "Loading..." is printed immediately before sleep.

printf() before scanf()	 Yes
