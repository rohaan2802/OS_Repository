Overview

Operating Systems at FAST-NUCES Islamabad, Spring 2025, with the labs done on Linux in C and C++. The course folder has the lecture slides grouped by topic, chapter summaries, my study notes, two textbooks, assignments, quizzes and the final project statement. The lab folder has the lab manuals, the example programs from each lab and my solutions to the lab tasks.

Unit 1

Basics & processes

OS structure, system calls, Docker, processes, PCB, fork and exec.

Unit 2

IPC & scheduling

Pipes, named pipes, signals and CPU scheduling algorithms.

Unit 3

Threads & synchronization

POSIX threads, critical sections, Peterson, Bakery, mutexes and semaphores.

Unit 4

Deadlocks & memory

Deadlock handling, address binding, paging and memory policies.

Get the Files

Clone everything with Git, then build any lab program on Linux with gcc or g++.

Clone the repository

Command
git clone https://github.com/rohaan2802/OS_Repository.git

Build and run a lab program

Command
cd "OS_Repository/OS LAB/LAB #05/i222327_lab_5"
gcc task2.c -o task2
./task2

Programs that use threads, semaphores or shared memory need -lpthread (and -lrt for POSIX semaphores). The labs use Linux system calls, so run them on Linux, WSL or inside Docker.
